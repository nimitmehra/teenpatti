The Family Card Table

A card table dressed the way a palace hotel would dress it.

Cream linen and ivory paper. Navy for the house, gold leaf for honour, green for play, garnet only for caution. Square corners, one frame per section, nothing that blinks.

The shapes

  • Square corners. Engraved brass and letterpress cards, not phone-app bubbles. 2px at most.
  • One frame per section. A gold double line, set in from the edge like a menu card. No boxes inside boxes.
  • Centred and symmetrical. Titles sit between two short gold rules; the player’s name sits on the centre line.
  • One navy band. Only the masthead is filled navy. Titles are navy lettering on ivory, so headings never look like buttons.
  • One solid button. The main move is solid green with a gold inner line; every other move is an ivory plate with a navy outline; Pack has a garnet outline.
  • Honour has a shape. Gold frame for the current player; an arched plaque for the winner. Nothing else is decorated.
  • Never: pills, pastel alert boxes, shadows, gradients, glows, emoji, or a colour that changes with a player’s status.
